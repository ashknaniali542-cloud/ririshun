# 可复用的领域检查规则

这些规则用于解释和复核，实际业务配置由接入方明确提供；当前工具不执行完整的多仓优化。

## 库存与调拨

采用 E/N 库存区分时：E 为可调出库存，工厂实际到货可进入 E；仓间到货进入 N，优先销售且不得再次调出。未到货的在途不提前增加可用库存。是否采用该规则由适用配置登记，不推定所有业务相同。

比较同状态、同需求情景下调拨与不新增调拨：全网增量销售贡献减去增量整车运费。全网销售变化已计入供出机会损失时，不重复扣减。车辆上限、计费、时间窗和搜索预算均从当前配置读取。

## 算法与检查边界

预测提供未来需求分布或情景，常态化或应急求解器输出方案。PPO 如用于 ALNS 算子控制，属于搜索内部；经验检索不等于 PPO 在线训练。

重量和体积合格不证明三维装载合格。边界、方向、不重叠、支撑、承重、装卸、轴载与重心由独立装载验证器负责；该验证器不包含在本包中。超时未找到方案不等于证明不可行。

## 数据来源

| source_scope | 含义 |
|---|---|
| enterprise_records | 企业业务记录，需说明单位与时间可得性 |
| enterprise_execution | 已核验的实际业务执行闭环 |
| enterprise_calibrated_scenarios | 依据企业记录校准生成的情景 |
| research_simulation | 研究仿真 |
| synthetic_development | 人工测试与演示 |

来源由可信登记与证据确定，不能由标签本身证明。现有工具要求经验同来源范围匹配；跨范围应用需要新的证据和条目。公开示例只使用 synthetic_development。
